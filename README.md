##1. Leukemia Gene Expression Dashboard
An interactive EDA dashboard for the GSE9476 leukemia dataset.
  
##2.Data Source
Kaggle
Dataset GSE9476 on leukemia gene expression from CuMiDa(Currated Microarray Database)
About Dataset= 5 classes(AML,Bone Marrow,PB,PBSC-CD34,Bone marrow CD34)
64 patients/samples
22284 genes


##3.Features
- Patient type distribution
- Interactive gene expression explorer
- Top 10 most variable genes
- Correlation heatmap
